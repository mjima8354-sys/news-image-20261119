# news-image-20261119

One image that sums up Thursday **19 November 2026**'s world news — a fully
deterministic, offline-rendered editorial poster (Pillow) for the
[make.fun news-image-20261119 bounty](https://make.fun/bounty/news-image-20261119).

## How it works
- `gen_news.py` renders `entry.png` (1024x1024, < 1 MiB) with Pillow — no network, no randomness.
- `main.py` copies `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).

## Stories covered
Trump-Xi-Putin trilateral summit (Shenzhen) · ICJ Rohingya judgment · Odesa strikes ·
Gulf intercepts Iranian drones · Nvidia halts H200 to China · GTA 6 launches after 13 years.
